Colour and contrast

Each swatch shows a foreground token on a background token with its WCAG contrast ratio. The ratio is recomputed in your browser from the live token values, so it stays correct in the dark theme (account menu, Appearance). Body text needs 4.5:1. Control boundaries, tag borders, focus rings and chart marks need 3:1.
