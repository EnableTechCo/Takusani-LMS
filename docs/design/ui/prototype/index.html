Prototype screens

Static screens for the 18 priority screens in the UX architecture, built on the design system. Every screen uses the same example data: Khanya Skills Institute, the 2026 Intake B cohort, and learner Lerato Mokoena. Nothing here saves, signs in, or sends anything.

For review21 Sep 2026

How to use these

Most screens have several states, such as a late submission or a refused action. Use the dashed Prototype controls box in the bottom right corner to switch between them. That box is not part of the design. Narrow the window to see the phone layout; the exam itself needs a window at least 1024 pixels wide.
