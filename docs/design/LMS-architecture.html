Consistency boundary

Critical academic transitions execute in PostgreSQL transactions. Final decisions and ledger entries are inserted, never overwritten.

Failure isolation

Outbox and queue processing keep email and scheduled work off the academic request path. Browser exams preserve local edits while disconnected.

Scope discipline

One institution, one deployable, one relational source of truth. Distribution is introduced only after a measured trigger.
